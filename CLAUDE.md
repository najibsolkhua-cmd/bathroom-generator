# Памятка проекта для Claude

Конструктор ванной комнаты для сайта строительной компании. Клиент выбирает параметры (и может загрузить фото своей ванной), сервер генерирует 5 вариантов через gpt-image-2, клиент выбирает понравившийся и оставляет заявку.

Общаться с владельцем проекта, писать комментарии в коде и сообщения коммитов — на русском.

## Структура

- `public/` — сайт (HTML/CSS/JS без сборки). Эта папка публикуется на GitHub Pages.
  - `index.html` — разметка; блок `APP_CONFIG` в начале — название компании, телефон, адрес сервера.
  - `css/style.css` — стили. Цвета и шрифты заданы переменными в `:root`.
  - `js/options.js` — варианты в фильтрах (что видит клиент). Читается и браузером, и сервером.
  - `js/app.js` — логика страницы: форма, фото, анимация загрузки, галерея, заявка, три режима работы.
  - `js/sketch.js` — SVG-эскизы для демо- и тестового режима.
  - `privacy.html` — шаблон политики конфиденциальности (с пропусками для данных компании).
- `server.js` — сервер на встроенных модулях Node.js 20+.
- `lib/prompt.js` — промпт для gpt-image-2 (на английском) и проверка параметров.
- `scripts/check-options.js` — сверяет варианты в `options.js` и `lib/prompt.js`.
- `deploy/` — настройки Nginx и systemd для VPS reg.ru.
- `.github/workflows/pages.yml` — публикация `public/` на GitHub Pages.

## Правила

- **Никаких внешних npm-пакетов.** Сервер работает на чистом Node.js, `npm install` не нужен. Не добавлять зависимости без явной просьбы владельца.
- **Ключи и токены только в `.env`**, который не попадает в git. Никогда не коммитить ключи, не вставлять их в `public/`.
- **Клиент не передаёт свой текст в промпт** — только id из списков. Не добавлять свободные текстовые поля, которые уходят в нейросеть.
- **Варианты фильтров меняются в двух местах**: `public/js/options.js` (русские названия) и `TEXT` в `lib/prompt.js` (описание для нейросети). После правки — `node scripts/check-options.js`.
- **Демо-режим на GitHub Pages должен работать без сервера.** Не ломать ветку `state.mode === 'demo'` в `app.js`.
- Тексты интерфейса: простые слова, без канцелярита, кнопка называет действие («Показать 5 вариантов», «Отправить заявку»).

## Проверка перед отправкой

```bash
node --check server.js && node --check public/js/app.js && node scripts/check-options.js
MOCK=1 PORT=3000 node server.js   # открыть http://localhost:3000 и пройти сценарий
```

Для изменений интерфейса — пройти сценарий в браузере на ширине 1440 и 390 px: выбор параметров → генерация → галерея → просмотр → заявка.

## Публикация

- Любой push в `main` запускает GitHub Actions: папка `public/` публикуется на https://najibsolkhua-cmd.github.io/bathroom-generator/ примерно за минуту.
- Там сайт работает в демо-режиме (эскизы вместо картинок, заявки не отправляются).
- Боевой сайт — на VPS reg.ru, обновляется командой из README («Обновить сайт после изменений»).

## Как вносить правки

- Мелкие правки (тексты, цвета, варианты фильтров, исправления) — сразу в `main`.
- Крупные изменения (новые функции, переделка сервера) — в отдельной ветке и через pull request, чтобы владелец посмотрел перед слиянием.
