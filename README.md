# Конструктор ванной комнаты

Одностраничный сайт для строительной компании. Клиент загружает фото своей ванной, за 5 коротких шагов выбирает стиль, цвет, отделку, сантехнику, свет и уровень отделки, может дописать пожелания своими словами — и получает 5 фотореалистичных вариантов ремонта именно своего помещения. Понравившийся вариант он отмечает и заказывает замер: заявка с фото помещения, конфигурацией и выбранным вариантом приходит в Telegram.

Генератор рисует только ванные и санузлы: фото и пожелания проверяются до генерации, каждая картинка — после. На каждой картинке — водяной знак компании.

Картинки делает модель OpenAI (**gpt-image-2** или **gpt-image-2.5-sunburst**). Из России она подключается через российского посредника API (ProxyAPI или аналог), поэтому клиентам VPN не нужен.

- Как устроена генерация и её рамки — [docs/generation.md](docs/generation.md)
- Откуда взялись фильтры (анализ рынка и покупателей) — [docs/filters.md](docs/filters.md)
- Посмотреть сайт на компьютере и телефоне рядом — страница `preview.html`

## Как это устроено

```
Браузер клиента ──► ваш сервер на reg.ru (Node.js) ──► посредник API ──► OpenAI (gpt-image-2.5)
      ▲                     │
      └── картинки ◄────────┘ сохраняются на вашем сервере
```

- `public/` — сам сайт: `index.html`, стили, скрипты.
- `server.js` — сервер. Хранит ключ API, собирает промпт, генерирует варианты по очереди, сохраняет картинки, считает лимиты, принимает заявки.
- `lib/prompt.js` — промпт для нейросети и правила «чтобы всё было реально построить».
- `lib/guard.js` и `public/js/guard-rules.js` — ограничение «только ванные».
- `public/js/options.js` — шаги и варианты в фильтрах.
- `public/img/watermark.png` — водяной знак (сейчас заглушка, замените на логотип).
- `public/img/photos/` — примеры фото с Unsplash для стилей и демо-режима.

Серверу нужен только **Node.js 20+**, внешних пакетов нет, `npm install` не требуется.

## Три режима работы

| Режим | Когда включается | Что происходит |
|---|---|---|
| Демо | Сайт открыт без сервера (например, на GitHub Pages) | Вместо генерации показываются примеры фото в выбранном стиле, заявки не отправляются |
| Тестовый | Сервер запущен, но ключ API не указан (или `MOCK=1`) | Весь путь работает по-настоящему, но вместо генерации показываются примеры фото. Деньги не тратятся |
| Рабочий | В `.env` указан ключ API | Настоящая генерация через модель OpenAI (по умолчанию gpt-image-2.5-sunburst) |

## Запуск на своём компьютере

1. Установите Node.js 20 или новее: https://nodejs.org
2. Скачайте проект и откройте папку в терминале.
3. Запустите:
   ```
   node server.js
   ```
4. Откройте http://localhost:3000. Без ключа сайт работает в тестовом режиме.

Чтобы включить настоящую генерацию:

1. Зарегистрируйтесь у посредника API (например, ProxyAPI), пополните баланс и получите ключ.
2. **Проверьте в их каталоге, что есть модель `gpt-image-2.5-sunburst` (или `gpt-image-2`) с методом `images/edits`** (редактирование по фото клиента) и недорогая текстовая модель с отметкой Vision для проверок (по умолчанию `gpt-6-luna`, она есть у ProxyAPI).
3. Скопируйте `.env.example` в `.env` и впишите ключ в `OPENAI_API_KEY`. Если у посредника другой адрес API, поменяйте `OPENAI_BASE_URL`.
4. Перезапустите сервер.

## Настройки (файл `.env`)

Все настройки с пояснениями — в `.env.example`. Главные:

| Параметр | Что значит | По умолчанию |
|---|---|---|
| `OPENAI_API_KEY` | Ключ посредника API | пусто → тестовый режим |
| `OPENAI_BASE_URL` | Адрес API посредника | `https://api.proxyapi.ru/openai/v1` |
| `IMAGE_MODEL` | Модель картинок | `gpt-image-2.5-sunburst` |
| `IMAGE_QUALITY` | Качество | `high` |
| `IMAGES_PER_JOB` | Сколько вариантов за генерацию (1–5) | `5` |
| `GUARD_MODEL` | Модель для проверки «только ванные» | `gpt-6-luna` |
| `VERIFY_OUTPUT` | Проверять каждую готовую картинку | `1` |
| `WATERMARK_FILE` | Водяной знак | `public/img/watermark.png` |
| `DAILY_LIMIT_PER_IP` | Генераций в сутки на одного посетителя | `3` |
| `GLOBAL_DAILY_LIMIT` | Генераций в сутки на весь сайт | `30` |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Куда слать заявки на замер | пусто → только в файл |
| `SMARTCAPTCHA_CLIENT_KEY`, `SMARTCAPTCHA_SERVER_KEY` | Яндекс SmartCaptcha | пусто → без капчи |
| `PUBLIC_URL` | Адрес сайта для ссылок в Telegram | пусто |

Все заявки дополнительно пишутся в файл `data/leads.jsonl`.

Название компании и телефон меняются в начале `public/index.html` (блок `APP_CONFIG`).

## Как поменять варианты в фильтрах

1. В `public/js/options.js` поменяйте, что видит клиент (названия, подписи, порядок шагов).
2. В `lib/prompt.js` в объекте `TEXT` поменяйте описание этого варианта для нейросети (на английском).
3. Проверьте, что списки совпадают:
   ```
   node scripts/check-options.js
   ```

Убирайте то, чего бригада не делает. Если вы не делаете душ без поддона, удалите `walkin` в обоих файлах, и клиент не сможет его выбрать.

Водяной знак: замените `public/img/watermark.png` на логотип компании (PNG с прозрачным фоном, примерно 1000×240 px).

## Деплой на VPS reg.ru

Нужен **VPS** (обычный виртуальный хостинг не подойдёт). Хватит минимального тарифа с Ubuntu 22.04 или 24.04.

```bash
# 1. Node.js 22 и Nginx
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash -
sudo apt install -y nodejs nginx git imagemagick

# 2. Проект
sudo git clone https://github.com/najibsolkhua-cmd/bathroom-generator.git /var/www/bathroom-generator
cd /var/www/bathroom-generator
sudo cp .env.example .env
sudo nano .env            # впишите ключ, PUBLIC_URL, Telegram
sudo mkdir -p data generated && sudo chown -R www-data:www-data data generated .env

# 3. Автозапуск
sudo cp deploy/bathroom.service /etc/systemd/system/
sudo systemctl enable --now bathroom
sudo systemctl status bathroom     # должно быть active (running)

# 4. Nginx (сначала замените ваш-домен.ru в файле)
sudo cp deploy/nginx.conf /etc/nginx/sites-available/bathroom
sudo ln -s /etc/nginx/sites-available/bathroom /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 5. Бесплатный SSL
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d ваш-домен.ru -d www.ваш-домен.ru
```

В панели reg.ru у домена добавьте A-запись с IP вашего VPS.

Обновить сайт после изменений:
```bash
cd /var/www/bathroom-generator && sudo git pull && sudo systemctl restart bathroom
```

Логи сервера: `sudo journalctl -u bathroom -f`

## Демо на GitHub Pages

Папка `public/` автоматически публикуется на GitHub Pages: https://najibsolkhua-cmd.github.io/bathroom-generator/ (компьютер и телефон рядом — `preview.html`). Там сайт работает в демо-режиме: интерфейс можно проверить и показать компании, но вместо генерации показываются примеры фото. Ключ API нельзя класть на GitHub Pages: его увидит любой посетитель.

Если нужно проверить страницу с GitHub Pages вместе с работающим сервером, добавьте к адресу `?api=https://ваш-сервер` и укажите адрес страницы в `CORS_ORIGINS` в `.env`.

## Перед запуском для клиентов

- **Персональные данные (152-ФЗ).** Заполните шаблон `public/privacy.html` и покажите юристу. Подайте уведомление в Роскомнадзор. Параметры и фото уходят в зарубежный сервис генерации, это трансграничная передача, о ней тоже нужно уведомить.
- **Капча.** Подключите Яндекс SmartCaptcha, иначе боты могут тратить ваш баланс.
- **Лимит у посредника.** Поставьте лимит расходов в личном кабинете посредника API.
- **Проверка реализуемости.** Сделайте 20–30 генераций и покажите прорабу. Где нейросеть рисует то, что нельзя построить, уточняйте правила в `lib/prompt.js`.

## Сколько это стоит

По прайсу ProxyAPI (октябрь 2026) у `gpt-image-2` и `gpt-image-2.5-sunburst` одинаковая цена за токены: 9 100 ₽ за 1 млн выходных и 1 520 ₽ за 1 млн входных. Но `gpt-image-2.5-sunburst` тратит на картинку в 4 раза меньше токенов: вертикальная 1024×1536 в высоком качестве — около 1 400 выходных токенов против 5 500 у `gpt-image-2`. Поэтому по умолчанию стоит `gpt-image-2.5-sunburst`.

| Модель и качество | Одна картинка | Генерация из 5 картинок | На 10 000 ₽ |
|---|---|---|---|
| `gpt-image-2.5-sunburst`, `high` (по умолчанию) | ≈ 17 ₽ | ≈ 85–95 ₽ | ≈ 110 генераций (≈ 550 картинок) |
| `gpt-image-2.5-sunburst`, `medium` | ≈ 8 ₽ | ≈ 40–45 ₽ | ≈ 230 генераций |
| `gpt-image-2`, `high` | ≈ 55 ₽ | ≈ 270–300 ₽ | ≈ 35 генераций |
| `gpt-image-2`, `medium` | ≈ 15 ₽ | ≈ 80 ₽ | ≈ 125 генераций |

В цену картинки входят выходные токены, фото клиента и текст промпта (≈ 4–5 ₽ на картинку). Проверки «только ванные» на `gpt-6-luna` — меньше 2 ₽ на генерацию. `IMAGES_PER_JOB=3` — 3 варианта вместо 5, генерация дешевле на 40%. Квадратные картинки (без фото клиента) примерно на четверть дороже вертикальных.

Точный расход виден в кабинете посредника: сверьте его после первых 10 генераций. `IMAGE_INPUT_FIDELITY=high` может увеличить расход на входное фото. Цены посредника меняются.

Чтобы не уйти в минус, держите `GLOBAL_DAILY_LIMIT` небольшим (по умолчанию 30 генераций в сутки ≈ до 3 000 ₽ в день) и поставьте лимит расходов в кабинете посредника.
