# Конструктор ванной комнаты

Одностраничный сайт для строительной компании. Клиент выбирает размер помещения, стиль, цвет, сантехнику и уровень отделки, может загрузить фото своей ванной и получает 5 вариантов дизайна. Если вариант понравился, клиент оставляет телефон, и заявка приходит менеджеру в Telegram.

Картинки делает модель **gpt-image-2** от OpenAI. Из России она подключается через российского посредника API (ProxyAPI или аналог), поэтому клиентам VPN не нужен.

## Как это устроено

```
Браузер клиента ──► ваш сервер на reg.ru (Node.js) ──► посредник API ──► gpt-image-2
      ▲                     │
      └── картинки ◄────────┘ сохраняются на вашем сервере
```

- `public/` — сам сайт: `index.html`, стили, скрипты.
- `server.js` — сервер. Хранит ключ API, собирает промпт, генерирует варианты по очереди, сохраняет картинки, считает лимиты, принимает заявки.
- `lib/prompt.js` — промпт для нейросети и правила «чтобы всё было реально построить».
- `public/js/options.js` — список вариантов в фильтрах.

Серверу нужен только **Node.js 20+**, внешних пакетов нет, `npm install` не требуется.

## Три режима работы

| Режим | Когда включается | Что происходит |
|---|---|---|
| Демо | Сайт открыт без сервера (например, на GitHub Pages) | Вместо картинок рисуются эскизы прямо в браузере, заявки не отправляются |
| Тестовый | Сервер запущен, но ключ API не указан (или `MOCK=1`) | Весь путь работает по-настоящему, но вместо генерации рисуются эскизы. Деньги не тратятся |
| Рабочий | В `.env` указан ключ API | Настоящая генерация через gpt-image-2 |

## Запуск на своём компьютере

1. Установите Node.js 20 или новее: https://nodejs.org
2. Скачайте проект и откройте папку в терминале.
3. Запустите:
   ```
   node server.js
   ```
4. Откройте http://localhost:3000. Без ключа сайт работает в тестовом режиме.

Чтобы включить настоящую генерацию:

1. Зарегистрируйтесь у посредника API (например, ProxyAPI), пополните баланс и получите ключ.
2. **Проверьте в их документации, что они поддерживают модель `gpt-image-2`** и метод `images/edits` (он нужен для режима «по фото»).
3. Скопируйте `.env.example` в `.env` и впишите ключ в `OPENAI_API_KEY`. Если у посредника другой адрес API, поменяйте `OPENAI_BASE_URL`.
4. Перезапустите сервер.

## Настройки (файл `.env`)

| Параметр | Что значит | По умолчанию |
|---|---|---|
| `OPENAI_API_KEY` | Ключ посредника API | пусто → тестовый режим |
| `OPENAI_BASE_URL` | Адрес API посредника | `https://api.proxyapi.ru/openai/v1` |
| `IMAGE_MODEL` | Модель | `gpt-image-2` |
| `IMAGE_QUALITY` | `low` / `medium` / `high` | `medium` |
| `IMAGE_SIZE` | Размер картинки | `1536x1024` |
| `IMAGES_PER_JOB` | Сколько вариантов за раз (1–5) | `5` |
| `DAILY_LIMIT_PER_IP` | Генераций в сутки на одного посетителя | `3` |
| `GLOBAL_DAILY_LIMIT` | Генераций в сутки на весь сайт (защита бюджета) | `200` |
| `MAX_PARALLEL` | Одновременных запросов к API | `4` |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Куда слать заявки | пусто → заявки только в файл |
| `SMARTCAPTCHA_CLIENT_KEY`, `SMARTCAPTCHA_SERVER_KEY` | Яндекс SmartCaptcha от ботов | пусто → без капчи |
| `PUBLIC_URL` | Адрес сайта, чтобы в Telegram приходили ссылки на картинки | пусто |
| `KEEP_DAYS` | Сколько дней хранить картинки | `14` |

Все заявки дополнительно пишутся в файл `data/leads.jsonl`.

Название компании и телефон меняются в начале `public/index.html` (блок `APP_CONFIG`).

## Как поменять варианты в фильтрах

1. В `public/js/options.js` поменяйте, что видит клиент (названия, подписи).
2. В `lib/prompt.js` в объекте `TEXT` поменяйте описание этого варианта для нейросети (на английском).
3. Проверьте, что списки совпадают:
   ```
   node scripts/check-options.js
   ```

Убирайте то, чего бригада не делает. Если вы не делаете душ без поддона, удалите `walkin` в обоих файлах, и клиент не сможет его выбрать.

## Деплой на VPS reg.ru

Нужен **VPS** (обычный виртуальный хостинг не подойдёт). Хватит минимального тарифа с Ubuntu 22.04 или 24.04.

```bash
# 1. Node.js 22 и Nginx
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash -
sudo apt install -y nodejs nginx git

# 2. Проект
sudo git clone https://github.com/najibsolkhua-cmd/bathroom-generator.git /var/www/bathroom-generator
cd /var/www/bathroom-generator
sudo cp .env.example .env
sudo nano .env            # впишите ключ, PUBLIC_URL, Telegram
sudo mkdir -p data generated && sudo chown -R www-data:www-data data generated .env

# 3. Автозапуск
sudo cp deploy/bathroom.service /etc/systemd/system/
sudo systemctl enable --now bathroom
sudo systemctl status bathroom     # должно быть active (running)

# 4. Nginx (сначала замените ваш-домен.ru в файле)
sudo cp deploy/nginx.conf /etc/nginx/sites-available/bathroom
sudo ln -s /etc/nginx/sites-available/bathroom /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 5. Бесплатный SSL
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d ваш-домен.ru -d www.ваш-домен.ru
```

В панели reg.ru у домена добавьте A-запись с IP вашего VPS.

Обновить сайт после изменений:
```bash
cd /var/www/bathroom-generator && sudo git pull && sudo systemctl restart bathroom
```

Логи сервера: `sudo journalctl -u bathroom -f`

## Демо на GitHub Pages

Папка `public/` автоматически публикуется на GitHub Pages. Там сайт работает в демо-режиме: интерфейс можно проверить и показать компании, но настоящей генерации нет. Ключ API нельзя класть на GitHub Pages: его увидит любой посетитель.

Если нужно проверить страницу с GitHub Pages вместе с работающим сервером, добавьте к адресу `?api=https://ваш-сервер` и укажите адрес страницы в `CORS_ORIGINS` в `.env`.

## Перед запуском для клиентов

- **Персональные данные (152-ФЗ).** Заполните шаблон `public/privacy.html` и покажите юристу. Подайте уведомление в Роскомнадзор. Параметры и фото уходят в зарубежный сервис генерации, это трансграничная передача, о ней тоже нужно уведомить.
- **Капча.** Подключите Яндекс SmartCaptcha, иначе боты могут тратить ваш баланс.
- **Лимит у посредника.** Поставьте лимит расходов в личном кабинете посредника API.
- **Проверка реализуемости.** Сделайте 20–30 генераций и покажите прорабу. Где нейросеть рисует то, что нельзя построить, уточняйте правила в `lib/prompt.js`.

## Сколько это стоит

Ориентир для gpt-image-2: примерно $0,04–0,07 за картинку в низком качестве, $0,07–0,15 в среднем и $0,15–0,35 в высоком, плюс наценка посредника. Пять картинок в среднем качестве обходятся примерно в $0,35–0,75 за одну генерацию. Точные цены смотрите у своего посредника.
